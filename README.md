# Tobacconist: Cravings

This is a 3rd party add-on to the [Tobacconist](https://github.com/diggydwarff/tobacconist) Minecraft mod. \
This mod adds nicotine cravings.

NeoForge 1.21.1 only. \
This mod has been tested to work with Tobacconist 4.2.0 Beta 2, but should work with 4.1.0 stable as well. \
Install on both Client and Server.

## Cravings

Only adds cravings if you've had the nicotine effect. Don't start and you won't get cravings. \
Cravings don't occur in Creative or Spectator.

### Mild: 10 minutes after last smoke
- Hunger
- Bad luck

### Moderate: 15 minutes after last smoke
- Mild
- Mining fatigue
- Weakness
- Nausea pulses

### Severe: 20 minutes after last smoke
- Moderate
- Darkness
- Slowness
- Blindness pulses

## Quitting

There is no quitting mechanic yet, I plan on having two methods: nicotine patch, cold turkey.
